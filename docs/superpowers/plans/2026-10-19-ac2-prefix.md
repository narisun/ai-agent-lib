# AC2_ Variable Prefix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement `docs/superpowers/specs/2026-10-19-ac2-prefix-design.md` — canonical `AC2_*` spellings for every library-owned variable, `EAP_*` kept working for one minor release with visible warnings, fail-closed policing of both vocabularies, and nothing else renamed.

**Architecture:** One constant flip (`PREFIX = "AC2_"`) renames every bound name, the owned-name regex, and the secret family; a systematic post-pass attaches each binding's `EAP_` spelling as a deprecated alias so the resolver's existing alias machinery (warning + differing-values conflict error) does the work. The three out-of-table families (secrets scan, Phoenix loader, UI reads) get explicit dual-reads with the same conflict rule. Deprecations become visible through the library logger (once per name per process); deploy passes legacy names through but flags them in its reviewable plan.

**Tech Stack:** Python 3.11+, pytest (+asyncio auto), ruff (line 100, Google docstrings), strict mypy, import-linter, Jinja templates, generated docs via `python -m ai_agent_lib_core.config ...` + `docs/guide/build_guide.py`.

## Global Constraints

- Worktree + `.venv/bin/python` for the main tree; UI commands from `packages/ai-agent-lib-ui` with its own `.venv/bin/python` (exists at `packages/ai-agent-lib-ui/.venv`).
- Known mypy noise: 8 Windows-only `[attr-defined]` errors (tools/local_processes.py, tests/architecture/test_stop_local.py, core test_http_windows_signals.py) + 1 in UI test_browser_protocol.py. Any NEW error is a finding.
- Generated artifacts change ONLY via generators, regenerated in the same commit: `docs/variables.md`, root `.env.example` (subcommands in `config/__main__.py`), `docs/developer-guide.html` (`build_guide.py`), generated-agent `.env.example`s (templates render in CLI tests).
- Frozen records are never edited: `docs/Specification.md`, `docs/design/*`, `docs/superpowers/*`, ADR historical text, dated verified-run records inside docs.
- Stays as-is (DO NOT TOUCH): repo/dist/import names, `agentlib` CLI, `.agentlib/` dirs, `agentlib.*/v*` schemas, OPA `agentlib/authz` + `policies/agentlib/rules/`, span attributes, MCP `_meta` keys, deploy resource defaults (`eap-audit`, `eap/{name}`, database `eap`), `RMPREP_CONTEXT_*`, third-party names (`AWS_*`, `PHOENIX_*`, `ANTHROPIC_API_KEY`, `OTEL_*`, `HTTPS_PROXY`, `NO_PROXY`).
- Conflict rule everywhere: equal values in both spellings coexist; differing values are a startup `ConfigurationError` naming both spellings.
- Commit per task, imperative subject, attribution trailer. Before each commit: focused tests, ruff check + format --check on touched packages, mypy once, lint-imports when imports changed.
