# Decision records

One file per decision, named `NNNN-short-title.md`, with four headings:
Context, Decision, Consequences and Owner. The open decisions are listed in
section 19 of the [target specification](../Specification.md).

- [0001: Container ownership and dependencies](0001-container-ownership.md)
- [0002: Pip workflow and generation](0002-pip-and-generation.md)
- [0003: Release contract](0003-release-contract.md)

The [release matrix](../release-scope.md) maps these decisions to code and tests.
